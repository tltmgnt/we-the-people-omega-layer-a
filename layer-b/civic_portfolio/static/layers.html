Boundaries and correction
D keeps exact text and immutable SHA-256 revisions with A/B/C confidence assertions. C requires definitions, units, cohort, exclusions, uncertainty, source revision pins, windows and counter-measures. Unknown values remain unknown; deltas are descriptive and are withheld for incomplete or stale pairs.
E records DRAFT → DESIGNED → BASELINE_RECORDED → REHEARSAL_RECORDED → EVALUATION_RECORDED → LEARNING_RECORDED. CHECK may pass or fail. REOPEN returns to draft while retaining history. ROLLBACK records withdrawal of a rehearsal or later phase; it does not undo any real-world action. Start again with REOPEN. Study/trial contracts are immutable: use a new ID for changed definitions or plans. Revise evidence under the same ID; correct observations by appending replacements and checking them again.
