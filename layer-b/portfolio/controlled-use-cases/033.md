## Every state

| State | Valid next states |
| --- | --- |
| CONTROL_SCOPED | DISCLOSURE_RECORD_RECORDED, WITHDRAWN |
| DISCLOSURE_RECORD_RECORDED | REVIEW_QUESTION_RECORDED, WITHDRAWN |
| REVIEW_QUESTION_RECORDED | CORRECTION_RECORDED, WITHDRAWN |
| CORRECTION_RECORDED | CHECK_RECORDED, WITHDRAWN |
| CHECK_RECORDED | CONTROL_REVIEW, WITHDRAWN |
| CONTROL_REVIEW | CLOSED, WITHDRAWN, REVIEW_QUESTION_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of CORRECTION_RECORDED and CHECK_RECORDED before CLOSED. Returning to REVIEW_QUESTION_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to CONTROL_SCOPED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure unresolved control findings and correction time; countercheck reporting burden.
