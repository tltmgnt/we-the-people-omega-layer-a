**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

**Bounded outcome:** Trace sanitation requests and missed-service corrections.

**Scenario evidence:** Routes, service events, missed pickups and complaints.

**Interpretation / safeguard:** Avoid publishing household-level identifiable service data.

## Every state

| State | Valid next states |
| --- | --- |
| ROUTE_PLANNED | SERVICE_RECORDED, WITHDRAWN |
| SERVICE_RECORDED | MISSED_SERVICE_RECORDED, WITHDRAWN |
| MISSED_SERVICE_RECORDED | RECOVERY_RECORDED, WITHDRAWN |
| RECOVERY_RECORDED | RECOVERY_REVIEW, WITHDRAWN |
| RECOVERY_REVIEW | CLOSED, WITHDRAWN, MISSED_SERVICE_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of MISSED_SERVICE_RECORDED and RECOVERY_RECORDED before CLOSED. Returning to MISSED_SERVICE_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to ROUTE_PLANNED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| missed_visits | COUNT / count | Fictional missed service visits | repeat_reports |
| repeat_reports | COUNT / count | Avoid publishing household-level identifiable service data; supplied fictional counter-measure | missed_visits |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure missed-service rate and correction time; countercheck repeat reports.
