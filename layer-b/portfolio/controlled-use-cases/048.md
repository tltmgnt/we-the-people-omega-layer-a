**Bounded outcome:** Publish a reproducible draft scorecard with uncertainty.

**Interpretation / safeguard:** Do not rank institutions using unvalidated composite scores.

## Every state

| State | Valid next states |
| --- | --- |
| METRICS_DEFINED | DENOMINATORS_RECORDED, WITHDRAWN |
| DENOMINATORS_RECORDED | BASELINE_RECORDED, WITHDRAWN |
| BASELINE_RECORDED | COUNTER_METRICS_RECORDED, WITHDRAWN |
| COUNTER_METRICS_RECORDED | REPRODUCTION_RECORDED, WITHDRAWN |
| REPRODUCTION_RECORDED | SCORECARD_REVIEW, WITHDRAWN |
| SCORECARD_REVIEW | CLOSED, WITHDRAWN, DENOMINATORS_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of COUNTER_METRICS_RECORDED and REPRODUCTION_RECORDED before CLOSED. Returning to DENOMINATORS_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to METRICS_DEFINED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| reproduction_failures | COUNT / count | Fictional reproduction failures; no composite rankings | missing_observations |
| missing_observations | COUNT / count | Do not rank institutions using unvalidated composite scores; supplied fictional counter-measure | reproduction_failures |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure reproducibility and correction timeliness; countercheck gaming and missing data.
