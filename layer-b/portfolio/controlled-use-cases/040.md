| AUTONOMY_CHECK_RECORDED | GOVERNANCE_REVIEW, WITHDRAWN |
| GOVERNANCE_REVIEW | CLOSED, WITHDRAWN, AUTHORITY_AGREEMENT_ASSERTED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of HANDOFF_RECORDED and AUTONOMY_CHECK_RECORDED before CLOSED. Returning to AUTHORITY_AGREEMENT_ASSERTED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to JURISDICTIONS_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.
