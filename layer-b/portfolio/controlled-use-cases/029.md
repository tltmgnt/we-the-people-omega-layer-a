## Every state

| State | Valid next states |
| --- | --- |
| AUTHORIZATION_ASSERTED | ASSET_RECORDED, WITHDRAWN |
| ASSET_RECORDED | FINDING_RECORDED, WITHDRAWN |
| FINDING_RECORDED | REMEDIATION_RECORDED, WITHDRAWN |
| REMEDIATION_RECORDED | RETEST_RECORDED, WITHDRAWN |
| RETEST_RECORDED | SECURITY_REVIEW, WITHDRAWN |
| SECURITY_REVIEW | CLOSED, WITHDRAWN, FINDING_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of REMEDIATION_RECORDED and RETEST_RECORDED before CLOSED. Returning to FINDING_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to AUTHORIZATION_ASSERTED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.
