## Every state

| State | Valid next states |
| --- | --- |
| QUESTION_SCOPED | BASELINE_RECORDED, WITHDRAWN |
| BASELINE_RECORDED | ALTERNATIVES_RECORDED, WITHDRAWN |
| ALTERNATIVES_RECORDED | ANALYSIS_RECORDED, WITHDRAWN |
| ANALYSIS_RECORDED | COMPARISON_RECORDED, WITHDRAWN |
| COMPARISON_RECORDED | POLICY_REVIEW, WITHDRAWN |
| POLICY_REVIEW | CLOSED, WITHDRAWN, ANALYSIS_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of BASELINE_RECORDED and COMPARISON_RECORDED before CLOSED. Returning to ANALYSIS_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to QUESTION_SCOPED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.
