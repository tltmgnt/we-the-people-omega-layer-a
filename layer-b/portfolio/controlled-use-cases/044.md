**Bounded outcome:** Measure end-to-end administrative burden for a selected workflow.

**Interpretation / safeguard:** Avoid invented composite scores and protect participant-level records.

## Every state

| State | Valid next states |
| --- | --- |
| PROCESS_SCOPED | EVENTS_RECORDED, WITHDRAWN |
| EVENTS_RECORDED | ACTIVE_TIME_RECORDED, WITHDRAWN |
| ACTIVE_TIME_RECORDED | WAITING_TIME_RECORDED, WITHDRAWN |
| WAITING_TIME_RECORDED | COUNTERCHECK_RECORDED, WITHDRAWN |
| COUNTERCHECK_RECORDED | BURDEN_REVIEW, WITHDRAWN |
| BURDEN_REVIEW | CLOSED, WITHDRAWN, EVENTS_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of WAITING_TIME_RECORDED and COUNTERCHECK_RECORDED before CLOSED. Returning to EVENTS_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to PROCESS_SCOPED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure elapsed and active time separately; countercheck errors and transferred burden.
