**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

**Bounded outcome:** Trace a bounded consumer-protection complaint workflow.

**Scenario evidence:** Complaints, referral events, response records and documented remedies.

**Interpretation / safeguard:** Avoid unverified allegations or automated enforcement and liability judgments.

## Every state

| State | Valid next states |
| --- | --- |
| COMPLAINT_RECORDED | SCOPE_RECORDED, WITHDRAWN |
| SCOPE_RECORDED | REFERRAL_RECORDED, WITHDRAWN |
| REFERRAL_RECORDED | RESPONSE_RECORDED, WITHDRAWN |
| RESPONSE_RECORDED | REMEDY_RECORDED, WITHDRAWN |
| REMEDY_RECORDED | REMEDY_REVIEW, WITHDRAWN |
| REMEDY_REVIEW | CLOSED, WITHDRAWN, RESPONSE_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of RESPONSE_RECORDED and REMEDY_RECORDED before CLOSED. Returning to RESPONSE_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to COMPLAINT_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure response time and verified remedy completion; countercheck repeated harm.
