# Project 025 — Food-assistance access

**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

## Run and control

From layer-b, Python 3.12:

    python -m civic_portfolio serve --port 8765

Open <http://127.0.0.1:8765/scenarios?workflow=p025>. Create a unique SYN- run with fictional actor/note and start timestamp. [Shared controller/API/backup instructions](../CONTROLLED-PORTFOLIO.md).

**Bounded outcome:** Trace food-assistance service capacity and access.

**Scenario evidence:** Service locations, availability, referral logs and supply interruptions.

**Interpretation / safeguard:** Avoid identifiable benefit-recipient reporting or automated eligibility decisions.

## Every state

| State | Valid next states |
| --- | --- |
| CAPACITY_RECORDED | REQUEST_RECORDED, WITHDRAWN |
| REQUEST_RECORDED | AVAILABILITY_RECORDED, WITHDRAWN |
| AVAILABILITY_RECORDED | SERVICE_RECORDED, WITHDRAWN |
| SERVICE_RECORDED | ACCESS_CHECK_RECORDED, WITHDRAWN |
| ACCESS_CHECK_RECORDED | NUTRITION_ACCESS_REVIEW, WITHDRAWN |
| NUTRITION_ACCESS_REVIEW | CLOSED, WITHDRAWN, AVAILABILITY_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of SERVICE_RECORDED and ACCESS_CHECK_RECORDED before CLOSED. Returning to AVAILABILITY_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to CAPACITY_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| unmet_requests | COUNT / count | Fictional unmet service requests | availability_gaps |
| availability_gaps | COUNT / count | Avoid identifiable benefit-recipient reporting or automated eligibility decisions; supplied fictional counter-measure | unmet_requests |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure service availability and unmet requests; countercheck nutrition and accessibility.

4. Close after a fresh pass, or withdraw. Record metric observations with explicit missingness/uncertainty; observe freshness after a new step or restore.
