# Project 013 — Housing referral

**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

## Run and control

From layer-b, Python 3.12:

    python -m civic_portfolio serve --port 8765

Open <http://127.0.0.1:8765/scenarios?workflow=p013>. Create a unique SYN- run with fictional actor/note and start timestamp. [Shared controller/API/backup instructions](../CONTROLLED-PORTFOLIO.md).

**Bounded outcome:** Trace a bounded housing-service referral and follow-up process.

**Scenario evidence:** Referral events, eligibility notices, placements and follow-up records.

**Interpretation / safeguard:** Protect housing and personal records; preserve appeal and consent processes.

## Every state

| State | Valid next states |
| --- | --- |
| REQUEST_RECORDED | CONSENT_ASSERTED, WITHDRAWN |
| CONSENT_ASSERTED | REFERRAL_RECORDED, WITHDRAWN |
| REFERRAL_RECORDED | SERVICE_START_RECORDED, WITHDRAWN |
| SERVICE_START_RECORDED | FOLLOW_UP_RECORDED, WITHDRAWN |
| FOLLOW_UP_RECORDED | CONTINUITY_REVIEW, WITHDRAWN |
| CONTINUITY_REVIEW | CLOSED, WITHDRAWN, REFERRAL_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of SERVICE_START_RECORDED and FOLLOW_UP_RECORDED before CLOSED. Returning to REFERRAL_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to REQUEST_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| referral_wait_minutes | MINUTES / minutes | Fictional referral wait | failed_handoffs |
| failed_handoffs | COUNT / count | Protect housing and personal records; preserve appeal and consent processes; supplied fictional counter-measure | referral_wait_minutes |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure referral-to-service time; countercheck failed referrals and service continuity.

4. Close after a fresh pass, or withdraw. Record metric observations with explicit missingness/uncertainty; observe freshness after a new step or restore.
5. Inspect all presets, reset/restore, reload, export and back up the workspace.
