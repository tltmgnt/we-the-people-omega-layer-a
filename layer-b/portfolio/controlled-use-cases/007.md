**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

**Bounded outcome:** Build civic research capacity through a bounded training and delivery cycle.

**Scenario evidence:** Training cohorts, role descriptions, exercises and feedback.

**Interpretation / safeguard:** Do not treat participation or attendance as proof of competence.

## Every state

| State | Valid next states |
| --- | --- |
| COHORT_PLANNED | EXERCISE_ASSIGNED, WITHDRAWN |
| EXERCISE_ASSIGNED | PRACTICE_RECORDED, WITHDRAWN |
| PRACTICE_RECORDED | ASSESSMENT_RECORDED, WITHDRAWN |
| ASSESSMENT_RECORDED | CAPACITY_REVIEW, WITHDRAWN |
| CAPACITY_REVIEW | CLOSED, WITHDRAWN, EXERCISE_ASSIGNED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of PRACTICE_RECORDED and ASSESSMENT_RECORDED before CLOSED. Returning to EXERCISE_ASSIGNED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to COHORT_PLANNED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| assessed_skill_gain | RATIO / proportion | Fictional assessed skill-gain proportion | participant_burden_minutes |
| participant_burden_minutes | MINUTES / minutes | Do not treat participation or attendance as proof of competence; supplied fictional counter-measure | assessed_skill_gain |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Track exercise completion and independently assessed skill gains; countercheck participant burden.

## Exercise and verify

1. Step through the declared path with fictional evidence notes and manual elapsed minutes.
2. Attempt closure before review, and review as either anchor recorder: both are rejected.
3. Use a separate checker, record failure then pass; return to the rework state to show the old check no longer applies.
4. Close after a fresh pass, or withdraw. Record metric observations with explicit missingness/uncertainty; observe freshness after a new step or restore.
5. Inspect all presets, reset/restore, reload, export and back up the workspace.
