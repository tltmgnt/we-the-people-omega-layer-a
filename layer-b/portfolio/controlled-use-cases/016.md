## Every state

| State | Valid next states |
| --- | --- |
| QUESTION_REGISTERED | AUTHORITY_CANDIDATE_RECORDED, WITHDRAWN |
| AUTHORITY_CANDIDATE_RECORDED | EVIDENCE_RECORDED, WITHDRAWN |
| EVIDENCE_RECORDED | CHALLENGE_RECORDED, WITHDRAWN |
| CHALLENGE_RECORDED | RESPONSE_RECORDED, WITHDRAWN |
| RESPONSE_RECORDED | CONDITIONS_REVIEW, WITHDRAWN |
| CONDITIONS_REVIEW | CLOSED, WITHDRAWN, EVIDENCE_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of CHALLENGE_RECORDED and RESPONSE_RECORDED before CLOSED. Returning to EVIDENCE_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to QUESTION_REGISTERED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.
