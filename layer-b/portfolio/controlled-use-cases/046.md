## Every state

| State | Valid next states |
| --- | --- |
| CURRENT_PROCESS_RECORDED | FUTURE_PROCESS_RECORDED, WITHDRAWN |
| FUTURE_PROCESS_RECORDED | CONTINUITY_PLAN_RECORDED, WITHDRAWN |
| CONTINUITY_PLAN_RECORDED | REHEARSAL_RECORDED, WITHDRAWN |
| REHEARSAL_RECORDED | ROLLBACK_TEST_RECORDED, WITHDRAWN |
| ROLLBACK_TEST_RECORDED | TRANSITION_REVIEW, WITHDRAWN |
| TRANSITION_REVIEW | CLOSED, WITHDRAWN, CONTINUITY_PLAN_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of REHEARSAL_RECORDED and ROLLBACK_TEST_RECORDED before CLOSED. Returning to CONTINUITY_PLAN_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to CURRENT_PROCESS_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure rehearsal success and recovery time; countercheck service interruption.
