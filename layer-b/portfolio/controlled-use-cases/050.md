## Every state

| State | Valid next states |
| --- | --- |
| SCENARIO_SCOPED | LAYER_A_HOLD_RECORDED, WITHDRAWN |
| LAYER_A_HOLD_RECORDED | LAYER_B_RECORD_RECORDED, WITHDRAWN |

| LAYER_C_OUTCOME_ASSERTED | LAYER_D_EVIDENCE_RECORDED, WITHDRAWN |
| LAYER_D_EVIDENCE_RECORDED | LAYER_E_ROLLBACK_RECORDED, WITHDRAWN |
| LAYER_E_ROLLBACK_RECORDED | CAPSTONE_REVIEW, WITHDRAWN |
| CAPSTONE_REVIEW | CLOSED, WITHDRAWN, LAYER_B_RECORD_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of LAYER_D_EVIDENCE_RECORDED and LAYER_E_ROLLBACK_RECORDED before CLOSED. Returning to LAYER_B_RECORD_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to SCENARIO_SCOPED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure reproducible scenario results and gate enforcement; countercheck unsupported assumptions.

This capstone needs an attached snapshot from a different, currently completed scenario with a current known measurement before CLOSED. It cannot attach itself or another capstone. Advancing the source makes the link stale; reattach and recheck. A CLOSED preset reuses valid attached evidence and otherwise rejects. Layer A always remains LEGAL_REVIEW_REQUIRED; this is a synthetic cross-layer bundle, not execution authority.
