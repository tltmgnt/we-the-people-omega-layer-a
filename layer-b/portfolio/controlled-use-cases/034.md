# Project 034 — Civic-information correction

**Editorial synthetic use case**, based on the registered title and proposed profile. Full source requirements and qualified/institutional acceptance remain outstanding. The implemented states rehearse recorded evidence and review; they do not perform actual services or validate the proposed method.

## Run and control

From layer-b, Python 3.12:

    python -m civic_portfolio serve --port 8765

Open <http://127.0.0.1:8765/scenarios?workflow=p034>. Create a unique SYN- run with fictional actor/note and start timestamp. [Shared controller/API/backup instructions](../CONTROLLED-PORTFOLIO.md).

**Bounded outcome:** Assess a bounded civic-information correction process.

**Scenario evidence:** Public claims, source references, verification notes and published corrections.

**Interpretation / safeguard:** Separate evidence from opinion; no censorship or individual credibility scoring.

## Every state

| State | Valid next states |
| --- | --- |
| CLAIM_RECORDED | SOURCES_RECORDED, WITHDRAWN |
| SOURCES_RECORDED | UNCERTAINTY_RECORDED, WITHDRAWN |
| UNCERTAINTY_RECORDED | CORRECTION_DRAFT_RECORDED, WITHDRAWN |
| CORRECTION_DRAFT_RECORDED | CHECK_RECORDED, WITHDRAWN |
| CHECK_RECORDED | INFORMATION_REVIEW, WITHDRAWN |
| INFORMATION_REVIEW | CLOSED, WITHDRAWN, SOURCES_RECORDED |
| CLOSED | None (terminal) |
| WITHDRAWN | None (terminal) |

The review state requires a passing current-path check by an identifier different from the latest recorders of CORRECTION_DRAFT_RECORDED and CHECK_RECORDED before CLOSED. Returning to SOURCES_RECORDED invalidates the prior check. Missing/failed/stale checks cannot close. Role identifiers are local assertions, not authenticated independent reviewers or officials.

Pause/resume/stop and manual TICK apply; paused/stopped workflows cannot step or review. Presets replay a shortest valid path, explicitly insert fictional checks and require PASS for CLOSED. Reset returns to CLAIM_RECORDED; RESTORE reproduces a prior snapshot in a new event without deleting history. WITHDRAWN is terminal and has null completion duration. No source/project/Layer A readiness is changed.

## Measurement contracts

| ID | Kind / unit | Supplied fictional measure | Counter-measure |
| --- | --- | --- | --- |
| unsupported_claims | COUNT / count | Fictional unsupported claims | missing_viewpoint_sources |
| missing_viewpoint_sources | COUNT / count | Separate evidence from opinion; no censorship or individual credibility scoring; supplied fictional counter-measure | unsupported_claims |

Use OBSERVE to record known values or explicit missingness. Proportions require integer numerator/positive denominator and numerator ≤ denominator; other metrics have no denominator. Counts/minor units require integers; minutes require finite nonnegative numbers. Missing values stay null. Every observation records evidence note, actor, path index and contract hash. New workflow steps make prior measurements stale; corrected observations append history. There are no invented denominators, causal conclusions, method-validation claims or composite scores.

The reporting period is this fictional branch; owner is a local assertion; exclusions are all live/person-level data; uncertainty is unverified supplied synthetic values. Counter-measures remain separate. The original proposed measurement question is: Measure citation coverage and correction time; countercheck uncertainty and viewpoint access.

## Exercise and verify

1. Step through the declared path with fictional evidence notes and manual elapsed minutes.
2. Attempt closure before review, and review as either anchor recorder: both are rejected.
3. Use a separate checker, record failure then pass; return to the rework state to show the old check no longer applies.
4. Close after a fresh pass, or withdraw. Record metric observations with explicit missingness/uncertainty; observe freshness after a new step or restore.
5. Inspect all presets, reset/restore, reload, export and back up the workspace.

Catalog-wide Python and browser tests exercise every profile/state, gate separation/revisions, invalid commands, metrics, snapshots, persistence, mobile layout and capstone dependencies. These checks establish software behavior, not institution-level results. Actual source import/review, real data contracts/governance, qualified acceptance and domain-specific operating/evaluation work remain outstanding.
