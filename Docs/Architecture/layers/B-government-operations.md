# Layer B — Government Operations

## User-supplied architectural purpose

Examines how public institutions convert lawful authority, public funding, personnel, information, procurement, and infrastructure into reliable services. It covers institutional operations, budgets, contracts, workforce capacity, records management, public works, and essential services.

## Current repository scope

Existing Layer B documentation, domain labs and a local synthetic portfolio/controller. This is not a live government operating system or accepted service implementation.
