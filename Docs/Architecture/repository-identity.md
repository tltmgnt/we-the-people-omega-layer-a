# WE THE PEOPLE Ω project identity

The project is **WE THE PEOPLE Ω — Layers A–E**. The existing GitHub repository name and URL remain unchanged.

## Five connected layers

| Layer | Name | Purpose |
| --- | --- | --- |
| A | Constitutional Legitimacy | Legal authority, rights, governance, ethics and accountability |
| B | Government Operations | Institutions, resources, procurement, workforce and service processes |
| C | Human and Community Outcomes | Meaningful effects on people and communities, with counter-measures and limitations |
| D | Intelligence and Evidence | Traceable sources, systems analysis, temporal capacity, uncertainty and validation |
| E | Transformation and Institutional Learning | Controlled pilots, review, transition, corrective action and learning |

## Scope and component names

The five-layer name describes the architecture and current synthetic prototypes. It does not establish completed institutional implementations, qualified acceptance or permission to operate public services.

Layer A remains **Constitutional Legitimacy**. Its schema, A1–A7 prompts, validator, statuses and legal-review holds retain that name. Historical import records keep the original Layer A context where it describes the actual history. The vendored Layer A provenance retains its pinned commit and unchanged schema bytes.

The `layer-b/` subtree remains the shared application's implementation location, including the dedicated C/D/E workspaces. `capacity-atlas/` contains the separate browser-local planning interface. Its hosted Site retains its own access and deployment settings.
